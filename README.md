# macOS Web Portfolio

An interactive macOS-inspired developer portfolio built with React 19, Tailwind CSS v4, and GSAP.

🔗 **Live Link**: [ahmedrasheed.vercel.app](https://ahmedrasheed.vercel.app/)

## Overview

This project recreates a macOS desktop layout inside the browser. It includes interactive app windows (Finder, Terminal, Safari, Photos), an animated desktop Dock with magnification physics, a top navigation bar with a live clock, and GSAP text weight interactions.

## Key Features

- **macOS Layout**: Top menu bar with live time formatting, wallpaper background, and desktop app windows.
- **Animated Dock**: Magnification effect on icon hover using GSAP.
- **App Windows**:
  - **Finder**: Project showcase with folder navigation and project details.
  - **Terminal**: Categorized view of tools and tech stack.
  - **Safari**: Articles and blog post previews.
  - **Photos**: Photo gallery grid layout.
  - **Contact & Resume**: Links to socials and resume download.
- **Variable Font Animations**: GSAP font weight modulation on mouse movement (`Georama` variable font).
